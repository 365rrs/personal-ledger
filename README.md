# Personal Ledger 个人账簿系统

基于 Spring Boot + Vue 3 的个人账簿管理系统，专门用于招商银行账单数据的导入、清洗、分析和管理。

## 快速开始

### 环境要求
- JDK 1.8+
- Maven 3.6+
- Node.js 16+
- npm 或 yarn

### 开发环境启动

#### 方式一：使用脚本启动（推荐）
```bash
# Windows
scripts\start-dev.bat
```

#### 方式二：手动启动

**启动后端服务：**
```bash
cd personal-ledger-backend
mvn spring-boot:run
```
后端服务将在 http://localhost:8080 启动

**启动前端开发服务器：**
```bash
cd personal-ledger-frontend
npm install
npm run dev
```
前端开发服务器将在 http://localhost:5173 启动

### 构建部署

```bash
# Windows
scripts\build.bat
```

构建完成后：
- 后端JAR包位于：`personal-ledger-backend/target/`
- 前端静态文件位于：`personal-ledger-frontend/dist/`

## API接口

### 主要接口
- `POST /api/cmb/import-full` - 导入招商银行CSV账单文件
- `POST /api/cmb/import-excel` - 导入系统导出Excel账单文件
- `POST /api/cmb/clean-records` - 清洗账单记录数据
- `GET /api/cmb/records` - 获取账单记录列表
- `POST /api/cmb/export` - 导出账单数据为Excel文件
- `PUT /api/cmb/records/{id}/remark` - 更新交易记录备注
- `PUT /api/cmb/records/{id}/include-in-summary` - 设置是否计入统计

### 接口特性
- 支持跨域请求（CORS）
- 文件上传限制：10MB
- 自动异常处理和错误响应
- 支持中文文件名导出
- 智能数据合并和去重处理
- 用户修改保护机制
- 支持CSV和Excel混合导入

## 使用说明

### 账单导入方式

本系统提供两种账单导入方式，满足不同用户的使用需求：

#### 1. 标准导入页面 (`/bill-import`)
**特点**:
- 现代化的引导式界面设计
- 分步骤操作流程，用户体验友好
- 丰富的视觉效果和动画
- 智能数据验证和清理功能
- 自动清理无效历史记录
- 响应式设计，支持移动端

**适用用户**: 新手用户、偶尔使用的用户

#### 2. 快速导入页面 (`/bill-import-simple`)
**特点**:
- 简洁直接的操作界面
- 可同时上传CSV和Excel文件
- 操作步骤更少，效率更高
- 适合批量处理文件

**适用用户**: 熟练用户、需要频繁导入的用户

#### 页面切换
两个页面之间可以相互切换：
- 标准版 → 快速版：点击"切换到快速导入"按钮
- 快速版 → 标准版：点击"切换到标准版"按钮

### 基础使用流程
1. **选择导入方式**：根据需要选择标准导入或快速导入页面
2. **导入账单**：上传CSV文件或Excel文件
3. **数据清洗**：点击"数据清洗"按钮优化数据质量
4. **筛选数据**：使用日期筛选器查看特定时间段的交易
5. **添加备注**：为交易记录添加个人备注信息
6. **数据分析**：
   - 按天统计：查看每日收支柱状图和月度日历热力图
   - 按分类统计：查看分类饼图和分类明细
7. **导出数据**：将处理后的数据导出为Excel文件

### Excel数据载体循环使用
1. **首次使用**：导入CSV文件 → 添加备注分类 → 导出Excel文件保存
2. **持续累加**：导入保存的Excel文件 → 导入新CSV数据 → 自动合并去重 → 导出更新的Excel文件
3. **数据保护**：用户的备注、分类、设置在合并时会被完全保留，不会被覆盖
4. **长期管理**：Excel文件作为数据载体，可实现跨月度、跨年度的数据积累管理

## Excel数据载体循环系统

本项目的最大亮点是实现了**Excel数据载体循环**，让Excel文件既是导出格式，也是数据存储载体。

### 🔄 数据循环流程
```
CSV导入 → 添加备注/分类 → 导出Excel → 保存Excel文件
    ↑                                           ↓
继续累加 ← 导入Excel ← 新的CSV数据 ← 重新导入Excel
```

### ✨ 核心优势
- **无需数据库**：Excel文件就是完整的数据存储
- **用户控制**：数据完全由用户管理，可备份、迁移、归档
- **渐进式累加**：可以逐步添加数据，不会丢失历史修改
- **跨设备使用**：在任何地方导入Excel即可恢复数据
- **数据保护**：用户的手动修改永久保留，不会被覆盖

### 📅 实际使用场景
**月度管理流程**：
1. 月初：导入上月的Excel文件（包含所有历史数据和用户修改）
2. 月中：导入新的CSV账单，自动合并到现有数据
3. 月末：添加备注、分类，导出新的Excel文件保存

**长期数据积累**：
- 1月：CSV → Excel_1月.xlsx
- 2月：Excel_1月.xlsx + 新CSV → Excel_2月.xlsx  
- 3月：Excel_2月.xlsx + 新CSV → Excel_3月.xlsx
- ...持续累加

## 数据分析功能

### 按天统计分析
- **柱状图展示**：每日收入、支出柱状图 + 累计支出折线图
- **日历热力图**：富途牛牛风格的月度日历，颜色表示盈亏
- **交互式查看**：点击图表或日历格子查看当日交易明细
- **数据标注**：图表上直接显示金额数值
- **快捷筛选**：支持今天、本月、上月、近3月、今年等快捷选择

### 按分类统计
- **饼图展示**：环形饼图显示各分类占比
- **收支切换**：可切换查看支出分类或收入分类
- **统计表格**：显示分类金额、笔数、占比、平均金额
- **分类明细**：点击饼图或表格行查看该分类的所有交易
- **自动分类**：未分类交易自动归入"未分类"组
