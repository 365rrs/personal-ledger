# Personal Ledger 个人账簿系统

基于 Spring Boot + Vue 3 的个人账簿管理系统，专门用于招商银行账单数据的导入、清洗、分析和管理。

## 快速开始

### 环境要求
- JDK 1.8+
- Maven 3.6+
- MySQL 5.7+
- Node.js 16+

### 启动步骤
1. **后端**：`cd personal-ledger-backend && mvn spring-boot:run`
2. **前端**：`cd personal-ledger-frontend && npm install && npm run dev`
3. **访问**：http://localhost:3000

## 核心功能

### 数据管理
- 📥 **CSV/Excel导入** - 支持招商银行账单导入，智能去重合并
- 🧹 **数据清洗** - 基于规则引擎的自动数据清洗
- 📝 **手动记账** - 支持手工添加交易记录
- 📊 **交易管理** - 完整的交易记录展示、编辑、筛选

### 数据分析
- 📈 **月度结余** - 月度收支结余分析
- 📉 **累计结余** - 累计结余趋势分析
- 💰 **大额交易** - 大额支出排行分析
- 🔄 **高频交易** - 高频消费商户分析
- 🥧 **分类统计** - 支出分类占比分析

### 系统管理
- 🏷️ **分类管理** - 自定义收入/支出分类，支持二级分类
- 💳 **渠道管理** - 自定义支付渠道
- ⚙️ **规则管理** - 配置数据清洗规则

## 技术栈

**后端**：Spring Boot + MyBatis-Plus + MySQL + Maven
**前端**：Vue 3 + Vite + Element Plus + ECharts
**数据库**：MySQL 8.0

## 使用说明

### 基础流程
1. **导入账单** - 上传CSV或Excel文件
2. **数据清洗** - 自动清洗和分类数据
3. **手动记账** - 补充手工交易记录
4. **数据分析** - 查看各种统计图表
5. **导出数据** - 导出Excel文件备份

### 数据循环
- CSV导入 → 添加备注分类 → 导出Excel保存
- 导入Excel → 新增CSV → 自动合并去重 → 导出更新Excel
- 用户修改永久保留，支持跨月度数据积累
