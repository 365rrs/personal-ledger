## 📋 新增/修改的API接口

### 统计相关
- `GET /api/bill/transaction/daily-stats` - 按天统计
  - 参数：startDate, endDate, category, paymentChannel
  - 返回：日期、收入、支出、结余、笔数
  
- `GET /api/bill/transaction/category-stats` - 按分类统计
  - 参数：startDate, endDate, type(income/expense)
  - 返回：分类、金额、笔数、占比

### 交易相关（已有）
- `GET /api/bill/transaction/list` - 交易列表（用于明细查询）
- `PUT /api/bill/transaction/{id}` - 更新交易（用于编辑）

## 🎯 核心优化点

### 性能优化
1. **数据统计后端化**
   - 数据库层面完成分组聚合
   - 减少前端数据传输量
   - 提升大数据量场景性能

2. **按需加载明细**
   - 点击时才加载明细数据
   - 避免一次性加载所有数据
   - 提升页面响应速度

### 用户体验优化
1. **交互增强**
   - 点击图表/表格查看明细
   - 右侧抽屉编辑，不遮挡主界面
   - 编辑后自动刷新相关数据

2. **信息完整性**
   - 明细表格展示所有关键字段
   - 计入收支状态可视化
   - 支持快速筛选和编辑

3. **管理页面统一**
   - 分类、渠道、规则管理样式一致
   - 统一的快速筛选交互
   - 更好的用户体验

## 💡 使用场景

### 按天统计分析
1. 选择日期范围、分类、支付渠道
2. 查看柱状图和累计折线图
3. 点击某天的柱状图
4. 查看当日交易明细
5. 点击编辑按钮修改分类或备注
6. 保存后自动刷新统计和明细

### 按分类统计
1. 选择收入/支出类型和月份范围
2. 查看饼图和统计表格
3. 点击饼图扇区或表格行
4. 查看该分类的所有交易
5. 编辑交易记录
6. 保存后自动刷新

### 管理页面
1. 分类管理：快速筛选全部/支出/收入
2. 支付渠道管理：快速筛选全部/启用/禁用
3. 规则管理：快速筛选全部/支付渠道/分类识别/备注清洗
