## 📋 新增API接口

### 导入相关
- POST /api/bill/import/csv - CSV导入
- POST /api/bill/import/excel - Excel导入
- GET /api/bill/import/list - 导入历史列表
- GET /api/bill/import/{id} - 导入详情
- DELETE /api/bill/import/{id} - 删除导入

### 交易相关
- GET /api/bill/transaction/list - 交易列表
- GET /api/bill/transaction/{id} - 交易详情
- PUT /api/bill/transaction/{id} - 更新交易
- DELETE /api/bill/transaction/{id} - 删除交易
