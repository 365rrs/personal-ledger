## 🗑️ 清理步骤

### 第一阶段：备份（安全起见）

```bash
# 创建备份分支
git checkout -b backup-before-cleanup
git push origin backup-before-cleanup

# 回到主分支
git checkout main
```

### 第二阶段：删除冗余文件

#### 1. 删除旧版统计页面
```bash
# 删除旧版按天统计
rm personal-ledger-frontend/src/views/DataAnalysis.vue

# 删除旧版按分类统计
rm personal-ledger-frontend/src/views/CategoryAnalysis.vue
```

#### 2. 删除未使用的页面（可选）
```bash
# 如果确认不需要导入历史功能
rm personal-ledger-frontend/src/views/BillImportHistory.vue

# 如果确认TransactionList冗余
rm personal-ledger-frontend/src/views/TransactionList.vue
```

### 第三阶段：清理路由配置

编辑 `src/router/index.js`，移除相关路由：

```javascript
// 删除这些路由（如果存在）
{
  path: '/data-analysis',
  name: 'DataAnalysis',
  component: () => import('@/views/DataAnalysis.vue')
},
{
  path: '/category-analysis',
  name: 'CategoryAnalysis',
  component: () => import('@/views/CategoryAnalysis.vue')
}
```

### 第四阶段：清理菜单配置

编辑 `src/components/Layout.vue`，确保菜单项正确：

```javascript
// 确保使用新版本的路由
{
  title: '按天统计',
  path: '/data-analysis-simple'  // 不是 /data-analysis
},
{
  title: '按分类统计',
  path: '/category-analysis-simple'  // 不是 /category-analysis
}
```

### 第五阶段：重命名文件（可选）

如果希望去掉 "Simple" 后缀：

```bash
# 重命名文件
mv DataAnalysisSimple.vue DataAnalysis.vue
mv CategoryAnalysisSimple.vue CategoryAnalysis.vue

# 同时更新路由配置中的路径
# /data-analysis-simple → /data-analysis
# /category-analysis-simple → /category-analysis
```
