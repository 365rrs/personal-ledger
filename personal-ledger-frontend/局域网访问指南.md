# 局域网访问指南

## 快速开始

### 1️⃣ 查看电脑IP

打开命令行，输入：
```bash
ipconfig
```

找到 **IPv4 地址**，例如：`192.168.1.100`

### 2️⃣ 启动服务

**后端（新窗口）：**
```bash
cd personal-ledger-backend
mvn spring-boot:run
```

**前端（新窗口）：**
```bash
cd personal-ledger-frontend
npm run dev
```

### 3️⃣ 在iPad上访问

打开Safari浏览器，输入：
```
http://192.168.1.100:3000
```
（把 `192.168.1.100` 替换成你的实际IP）

## ✅ 完成！

现在iPad应该可以正常访问和使用所有功能了。

## 常见问题

**Q: 显示"无法连接"？**
- 确保电脑和iPad在同一个WiFi
- 检查Windows防火墙是否允许端口3000和8080

**Q: 页面能打开但显示"网络异常"？**
- 确认后端服务正在运行
- 在iPad浏览器输入 `http://你的IP:8080/api/category/list` 测试后端

**Q: 需要每次都查IP吗？**
- 如果路由器设置了DHCP，IP可能会变
- 可以在路由器中为电脑设置固定IP

## 技术说明

系统会自动根据访问地址调整API请求：
- 本地访问 `localhost:3000` → API: `localhost:8080`
- 远程访问 `192.168.1.100:3000` → API: `192.168.1.100:8080`

无需手动配置！
